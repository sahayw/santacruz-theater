Astro static site for the Santa Cruz Theater, deployed via Netlify.

## Getting started

```sh
nvm use          # uses Node 20 from .nvmrc
npm install
npm run dev      # http://localhost:4321
```

## Build & deploy

```sh
npm run build    # outputs to dist/
npm run preview  # preview the production build locally
```

Netlify CI picks up pushes to `main` automatically using the config in `netlify.toml`.
